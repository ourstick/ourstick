# ADR 0022: The whole ticket in the link's fragment

**Status:** accepted — 2026-10-09, by Giorgos, before the first release.

## Context

A sharing link was `https://ourstick.com/s/<public>#<secret>`. The secret
(the stick key) was in the fragment, which a browser never sends; the public
part was in the path. The public part holds the stick id, the owner's node
id and up to eight address hints: the sender's relay and its direct IP
addresses, on the LAN and public (`transport/iroh/mod.rs`).

Until now ourstick.com served nothing. With the site (the page a link opens
without the app), every link opened in a browser would hand the site's host
(Cloudflare, in its request logs) who and where the sender is; so would the
link previews of chat apps, whose servers fetch the address of every link
posted.

## Decision

1. The link is `https://ourstick.com/s/#<public>.<secret>`: both parts in
   the fragment, separated by a dot (outside the base32 alphabet, safe in
   a fragment, and not a character link detectors stop at in the middle of
   a word). The bare form is `<public>.<secret>`. The bytes of both parts
   are unchanged (ticket format version 1).
2. The old form is not read. No one outside our tests ever had a link, and
   the test links were ended (2026-10-09). A received stick whose link was
   kept in the old form does not open; it is forgotten and added again.
   Our site's address with less after it than `/s/#` (a link cut short, or
   the old form) is "damaged or incomplete".
3. The page at `/s/` is a plain file: no rewrite, nothing of the ticket in
   any path the server sees. It checks only that the fragment has both
   parts, to say "This link is not whole" without the app.

## Consequences

- The site's host, and a chat app's link preview, see only that a link to
  `/s/` was opened. Anyone who has the link still sees the sender's
  addresses: the app needs them to connect.
- An Android App Link (todo) matches on `/s/` alone, which still works.
- `protocol.md` ("Ticket", text form), `CLAUDE.md`, the test vectors
  (regenerated by the independent Python implementation: only the links
  changed), the examples in the CLI and the app, and the site.
